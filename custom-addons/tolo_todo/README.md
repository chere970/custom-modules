# tolo_todo — Odoo 19 starter (incomplete)

For the Tolo Solutions Junior live practical.

## Requirements
- **Odoo 19**
- Copy this `tolo_todo` folder into your addons path

## Install
1. Add the parent `addons` folder to your Odoo addons path (or copy `tolo_todo` next to other addons).
2. Restart Odoo / update apps list.
3. Install **Tolo Todo**.
4. After code changes: **Upgrade** the module (do not only restart).
